  replacements. State how each proposed feature supports the charter.

  product direction. Charter amendments require explicit founder approval.

  Work in the canonical checkout `C:\inetpub\Chimera2`.
- Verify functionality and usability against the charter's representative tasks;
  report automated evidence and human review separately. Successful tests never
  establish founder acceptance. Retain existing delivery and qualification gates.
- Work locally first. Merging, migration, deployment and paid generation require
  explicit authorization. Major charter changes require explicit founder approval.
- Stop for founder review before committing the initial charter or these instructions;
  commit only when explicitly authorized.
