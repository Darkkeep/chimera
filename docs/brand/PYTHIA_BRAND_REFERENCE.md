# Pythia Brand Reference

Pythia's canonical visual identity is owned by **Darkkeep/Pythia**.

**Approved identity:** *Pythia App Icon — Emergent Vision (Concept 4)*  
**Canonical standard:** `Darkkeep/Pythia/docs/brand/PYTHIA_BRAND_STANDARD.md`

Consumer rule: use the Pythia icon only where a surface, action, artifact, question, or status is specifically owned by the Pythia engine. It identifies engine ownership and must not replace this product's own brand.

The approved mark is the hooded oracle at the luminous tripod bowl, with the crescent/oracle/bowl vertical axis and cyan signal flow on a deep navy-black field. Do not substitute earlier concepts, recolor it, add text inside it, or fork the visual identity.

For current production assets, consume the master files from Pythia's `docs/brand/assets/` directory or an explicitly synchronized application copy.
