# Accessibility Notes

The cinematic identity is allowed to be dramatic; the authoring environment must remain calm and legible.

- Body copy: White Hot or Titanium on Void/Carbon.
- Disabled text should still remain readable; do not drop opacity below roughly 55% without testing.
- Ignition orange is not a body-text color on light backgrounds.
- Cyan Signal is the preferred keyboard-focus color because it remains distinct from the brand-action orange.
- Validation: pair status color with label + icon.
- Keep glow outside text glyphs.
- Dark theme is primary; light exported learning content is independent of the authoring shell.
