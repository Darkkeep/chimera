# Motion Language

CHIMERA motion should feel **assembled, vectored and deliberate**, not floaty.

## Timing
- micro interaction: 120 ms
- normal UI transition: 180 ms
- panel/reconfiguration transition: 260 ms

## Motifs
- panels slide on a single axis with a short deceleration
- selected states can use a 1–2 px ignition sweep
- compile/deploy states may use segmented progress that assembles left-to-right
- AI enhancement proposals may enter as stacked layers that resolve into one selected state

## Avoid
- perpetual pulsing
- smoke/fire effects inside normal work screens
- springy/bouncy navigation
- gratuitous parallax

Honor `prefers-reduced-motion`.
